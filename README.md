# CatCode Packaging Report

Records the packaging weight of every WooCommerce order by material type and turns it into a report you read instead of rebuild.

This repository mirrors the free version published on wordpress.org, version 1.0.2.

## Requirements

- WordPress 6.2+ (tested up to 7.1)
- WooCommerce 6.0+ (tested up to 10.7)
- PHP 7.4+

## Install

Install from the WordPress plugin directory (Plugins → Add New → search for the plugin name), or download this repository and upload it to `wp-content/plugins/catcode-packaging-report/`.
